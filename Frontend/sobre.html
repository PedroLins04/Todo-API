A PROPOSTA

Menos complicação.
Mais organização.

A proposta do KeepTheFlow é reunir o gerenciamento de tarefas em uma interface visual e objetiva. Organize o que precisa ser feito, acompanhe o que está pendente e veja o que já foi concluído — sem perder de vista suas prioridades.

FUNCIONALIDADES

Feito para acompanhar seu ritmo.

Recursos para deixar seu fluxo de trabalho mais claro.

Quadro Kanban

Visualize tarefas pendentes e concluídas e mova cartões para atualizar o progresso.

Prioridades

Classifique tarefas por prioridade e identifique o que merece atenção primeiro.

Busca e acompanhamento

Encontre tarefas com facilidade e acompanhe os totais de pendências e conclusões.

Conta individual

A autenticação protege o acesso e mantém as tarefas vinculadas à conta correspondente.

POR TRÁS DA APLICAÇÃO

Uma experiência simples,
construída com tecnologia.

O projeto combina uma interface web com uma API REST responsável pelas regras de negócio, autenticação e persistência dos dados.

BackendJava · Spring Boot · Spring Security · JWT
DadosPostgreSQL · Spring Data JPA · Flyway
FrontendHTML · CSS · JavaScript · Bootstrap
Testes e execuçãoJUnit · Mockito · MockMvc · Docker
